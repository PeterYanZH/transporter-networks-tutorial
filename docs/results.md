# 结果、证据与复现边界

本仓库继承 Transporter Networks / Ravens 的方法与官方权重，提供非官方教学复现。这里将**历史实验记录**与**公开仓库整理时的新验证**分开，避免把脚本整理、图像重绘或同一场景的重复运行当作新增泛化实验。

## 历史模型与环境证据

历史记录保存在 [`evidence/historical/`](../evidence/historical/)。这些材料来自 2026-09-21 开始的 CPU 最小复现及随后的教学整理。该目录是对照记录；复跑入口将新结果写入 `results/` 或 `teaching/results/`。

| 项目 | 历史记录 | 证据文件 | 能支持的结论 |
| --- | --- | --- | --- |
| 上游版本 | `4752ffab487ebd387781ad7890aa540ae2780970` | `reproduction-summary.json` | 本仓库解释对应一个明确源码版本 |
| 环境 | Ubuntu 22.04、Python 3.10.12、TensorFlow CPU 2.15.1、Keras 2.15.0、Addons 0.23.0 | `environment.json` | 所记录 CPU 配置成功运行；不支持 GPU 已适配的结论 |
| 小规模资产 | 10 条训练示范、3 条测试示范、两份官方权重；67 个文件 | `reproduction-summary.json` 的 `assets` | 只取一个任务所需子集，无须下载所有任务 |
| 单步训练 | 一次迭代，两分支各一次优化器更新；loss 10.9863 / 269.8396；保存后重新加载通过 | `train_smoke.json` | 数据读取、增广、前后向、更新、保存与加载链路可用；不代表训练收敛 |

## 历史教学诊断

原始统计见 [`model_metrics.json`](../evidence/historical/model_metrics.json)。可重绘的数组和工作结果位于 [`teaching/results/`](../teaching/results/)。诊断使用同一官方模型，**参数更新数为零**。

| 诊断 | 实验单位 | 历史数值 | 解释范围 |
| --- | --- | --- | --- |
| 闭环图像回放 | 种子 1、3、5 的三个既有场景 | 每个场景一次动作，奖励 1.0 | 与前面的预训练检查使用相同种子，不能相加为六个独立测试 |
| 改变抓点条件 | 种子 1 的一张固定观测，三个抓点 | 平面参照误差 4.4194、8.8388、3.1250 mm；方向索引 15、14、15 | 后两个条件只前向推理；误差基于像素量化的刚体参照，不是末端实测精度 |
| 输入平移 | 同一张量，六种位移 | 见下表 | 图像和抓点同步移动，非六次新的物理场景测试 |
| Query 局部梯度 | 同一输入的一个选定特征 | 裁剪外梯度质量占比 0 | 证明该局部导数的计算支持域，不等价于区域因果重要性 |

平移度量在去掉四边各 32 像素的内部区域分别重新归一化后计算：

| 位移 `(Δr, Δc)` / px | 抓取分布内部 TV | 放置峰位误差 / px | 放置方向索引 |
| --- | ---: | ---: | ---: |
| `(0, 0)` | 0 | 0 | 15 |
| `(1, 0)` | 0.0646591 | 0 | 15 |
| `(0, 1)` | 0.1043593 | 0 | 15 |
| `(8, 0)` | 4.2907e-8 | 0 | 15 |
| `(0, 8)` | 2.9705e-8 | 0 | 15 |
| `(8, 8)` | 6.3492e-8 | 0 | 15 |

峰位误差为零与 TV 非零并不矛盾：一个度量最大位置，另一个度量完整内部概率分布。当前结果与步长 8 的采样相位一致，但不能推出任意场景或任意几何变化都严格等变。

## 历史合成算例

见 [`toy_metrics.json`](../evidence/historical/toy_metrics.json) 及 [`teaching/toys/`](../teaching/toys/)。这些例子不含 CNN，也不执行机器人动作。

| 算例 | 历史结果 | 不应作出的推论 |
| --- | --- | --- |
| 四接触岛的回归与分类 | MSE 得到 `(20,20)` 的非法均值；四个标签各约 0.249799；合法区域概率约 99.9248% | 两坐标与 1,681 个自由 logits 的参数量不同，不能当作公平网络消融或泛化成绩 |
| 五候选全局 Softmax 梯度 | 有限差分与 `p-y` 的最大绝对误差约 2.4444e-10；梯度和约 1.3878e-17 | 对 logits 的零和性不是共享网络每个输出在更新后都必然单调变化的保证 |
| L 形身份特征相关 | 相同方向的整数平移重叠域误差为 0 | 这是无学习、无裁断的构造，不能证明真实网络的任意平移/旋转等变性 |
| 三通道 Query/Key | 首窗口 6，右移窗口 17；完整图为 `[[6,17,13],[17,9,11],[11,10,7]]` | 人工特征评分不是模型真实激活，不是归一化概率，也没有唯一最大值 |

三通道示例数值另见 [`sliding_correlation.json`](../teaching/figures/sliding_correlation.json)。精修稿中的原论文基准表仍属于论文来源结果，不能并入本仓库的实验统计。

## 尚未实现或验证

- 论文全部任务、示范规模、多个训练随机种子与完整评测集。
- 从头完整训练、对比架构消融、GPU 或新显卡兼容路径。
- 新物体、新视点、背景干预、真实机器人接触精度等泛化评估。
- 精修稿中的 VLA、ReconVLA、世界模型、最差组指标与区域反事实干预实验。

项目可用于学习 Transporter 的结构、复跑最小闭环和构造后续实验。对算法效果的统计结论，仍需按明确的任务分布、样本量和对照设置开展新的实验。
